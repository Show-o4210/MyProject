# 变更记录

本文件记录影响开发、部署或数据维护的重要变更。面向网站访客的完整更新信息由 `data/news.json` 维护。

## 2026-10-03 · 首页与公共导航精简

- 首页改为紧凑工具入口，保留一条折叠公告和三条默认收起的最近更新，历史记录按需展开。
- 移除重复 Unity 按钮、英文标签、首页赞助卡及自动赞助弹窗；公共导航和背景统一简化。
- 首页由 Jinja 直接渲染，日志使用原生 details，不再加载 Vue；赞助入口使用原生 dialog，保留主动打开、关闭与键盘操作。

## 2026-10-03 · Unity 文本工具与界面精简

- 保留 JSON/CSV 导出与回填，只处理 MonoBehaviour / TextAsset；移除独立结构检查及其接口。
- 移除图片导出、贴图回填、DAT/raw 替换、高级对象选择及重复预设，并清理专用预算与直接 Pillow 依赖。
- 保留 JSON5、尾逗号、索引匹配与引用兼容；旧选项和不支持的补丁返回明确错误。
- 采用紧凑双页签表单，JSON/CSV 直接选择，兼容选项默认折叠，错误与处理状态就近显示。

## 2026-10-03 · 下载中心精简

- 资料卡片点击后直接弹出夸克网盘和 QQ 群入口，移除重复介绍与详情页。
- 下载配置改为扁平列表，删除分区、版本日期、说明和逐文件兼容接口；同步简化校验脚本与 sitemap。

## 2026-10-03 · 反馈中心下线

- 因长期没有新增内容，移除反馈页面、提交 API、业务服务和专用建表脚本，并清理导航、首页卡片与 sitemap。
- 删除反馈专用的 JSON 限额、错误响应、内容检测与路径规则；保留通用限流、客户端 IP 和安全审计。
- 清理反馈专用回归测试，保留关卡请求预算与通用安全回归；首页公告说明下线。

## 2026-10-03 · EA 账号工具下线

- 移除卡牌发送、卡包购买和账号库存查验的页面、后端 API、旧地址兼容跳转、公共请求模块及专用卡包数据。
- 清理首页入口、SEO 描述、动态与静态 sitemap、构建脚本、EA 配置示例和维护文档。
- 首页公告说明使用量较少、长期维护成本较高，停止提供 EA 账号工具；其他 Mod 工具继续保留。

## 2026-10-03 · DIY v4.13.1 补丁

- DIY APK 版本信息同步为 v4.13.1 / 41301，补丁说明包含键盘避让、紧凑预览和光标行可见性优化。

- APK 由用户替换到现有网盘分享中；未修改网站其他功能。
