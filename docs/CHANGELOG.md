# 变更记录

本文件记录影响开发、部署或数据维护的重要变更。面向网站访客的完整更新信息由 `data/news.json` 维护。

## 2026-08

- 下载中心改为适配手机竖屏的紧凑长条列表，详情与下载入口分离。
- 取消逐文件 GitHub 镜像竞速，统一使用夸克网盘与 QQ 群两种获取方式。
- APK 版本数据更新至 `v4.8.1`（`version_code: 40801`）。
- 更新下载目录与赞助名单数据。
- 调整安全检查逻辑。

## 2026-07

- Web 公告版本更新至 3.7。
- 清理不再读取的旧卡牌索引与兼容逻辑，全站统一使用 `data/index_new.json`。
- 下载中心增加 GitHub 多镜像竞速、失效源剔除、单文件与作品包支持。
- 完成下载目录 `sections[]` 结构规范化，并加入校验脚本。
- 加固 Unity 回填流程，改善 JSON 错误提示、保存回退和 PPtr 修复。
- 修复 TextAsset `m_Script` 展开/回填与 CSV 转义问题。
- 统一真实访客 IP 获取、限流、安全审计和自唤醒识别。
- 反馈写入改为 Supabase `INSERT` 后不回读，以适配 anon INSERT-only 策略。
- 使用 WhiteNoise 托管静态资源，补齐根路径 robots、sitemap、canonical 和 favicon。
- 改进赞助名单与支持入口。

## 2026-06

- 移除旧账号与社区系统，项目收敛为工具站。
- 业务按蓝图、服务和工具模块拆分。
- 卡组、关卡与幻影工具统一使用新版卡牌索引。
- 幻影引擎恢复并持续完善。

更早的访客侧更新记录仍保存在 `data/news.json`。
